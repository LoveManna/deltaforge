## 2. What you need to know before you commit anything

**The repository is public.** It was flipped with `gh api -X PATCH repos/LoveManna/deltaforge
-F private=false` after a scan of every ref for committed secrets (`.env` has never been
tracked; every `VAST_API_KEY` hit in history is a variable name, a test fixture with a fake
key, or the CI secret-scan job itself). From here:

* Anything you commit and push is world-readable, `ledger/spend.jsonl` and
  `docs/GPU-ACCESS.md`'s machine IDs included.
* The CI secret-scan in `.github/workflows/ci.yml` is now load-bearing.
* A retracted number stays visible until the prose carrying it is fixed. §6.1 already says
  to fix what a session disproved; it is now the difference between a stale line and a
  public one.

**`origin/main` is 112 commits behind this branch.** The public repository's front page is
therefore the `fm/df-bootstrap` state: no batches, no champions, no leaderboard worth
reading. The live page at github.io is current and the repository it points at is not.
Nothing in this session pushed the working branch, because committing was asked for and
pushing was not. **If the public repository is meant to be read by the people the page is
for, this is the first thing to fix** — `git push origin batch/012-the-matmul-dtype` and a
PR to `main`, or a fast-forward of `main` if the branch flow has served its purpose.

## 3. The three copies of the write-up, and which one is the source

| Copy | Format | Who updates it |
|---|---|---|
| `RESULTS.md` | Markdown, in the repo | **the source of record for the words** |
| `site/index.html` | standalone HTML, in the repo | built by hand from `RESULTS.md`; same numbers, same order |
| `gh-pages:index.html` | the same file, served | a copy of `site/index.html` — never edit it in place |

A fourth copy exists outside the repository: a private artifact on claude.ai
(`claude.ai/artifact/TKFXWkZ1FoLKJxfmUwgtxD`), which is where the page was authored. It is
not reachable by anyone the owner has not shared it with, it does not update itself, and it
will drift. Treat the repository as authoritative; the owner was asked whether to delete it
and had not answered when this file was written.

`site/README.md` has the three commands that publish a change to the page. The shape of it:

```sh
git worktree add --detach /tmp/df-pages
git -C /tmp/df-pages switch gh-pages      # orphan branch: index.html + .nojekyll, nothing else
cp site/index.html /tmp/df-pages/index.html
git -C /tmp/df-pages commit -am "Update the page" && git -C /tmp/df-pages push
git worktree remove /tmp/df-pages
```

`.nojekyll` is load-bearing — without it GitHub runs Jekyll over the branch. Pages is
configured as `source: {branch: gh-pages, path: /}` and enabled itself when the branch was
first pushed; `gh api repos/LoveManna/deltaforge/pages` reports its status.

**Keeping them in step is not optional.** `LEADERBOARD.md`, `RESULTS.md` and
`site/index.html` carry the same headline numbers in the same order. A rental that moves a
champion moves all three.
